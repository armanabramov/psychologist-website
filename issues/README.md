# Работа с GitHub Issues

Здесь не ведётся параллельный список статусов: **канонический трекер — вкладка [Issues](../../issues)**.

Каждая задача имеет ясный результат, чек-лист и привязку к документации. Закрываем Issue после фактического выполнения критериев. Новые договорённости из обсуждений фиксируем в соответствующем документе `docs/`, а не только в комментариях.

Группы: research, brief, content, ux, design, dev, integrations, quality, launch.
