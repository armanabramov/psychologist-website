# Сайт психолога

Персональный сайт психолога: представить специалиста, объяснить, с какими запросами он работает, показать образование и опыт, описать услуги и помочь посетителю записаться.

> **Статус:** исследование и подготовка. Бриф с заказчицей ещё не проведён. Все содержательные решения пока предварительные.

## Цель и формат

- **MVP:** спокойный, понятный одностраничный сайт без избыточной функциональности.
- **Главный сценарий:** доверие → понимание запросов и услуг → запись на консультацию.
- **Визуальный ориентир:** тёплая натуральная палитра Dulux; минимализм, читаемость, живые фотографии.
- **Отзывы:** отдельно исследовать официальный способ отображения отзывов «ПроДокторов»; не обещать автоматическую интеграцию заранее.
- **Статьи:** опционально, по наличию контента; полноценный блог — отдельное решение.
- **Стек:** определим после уточнения функциональных требований и потребностей в редактировании.

## Работа с Issues

Один Issue = один проверяемый результат. Итоги исследования и согласованные решения записываем в документы и ссылаемся на них из Issues. Закрываем задачи после выполнения критериев, новые добавляем по мере появления требований. Дорожная карта — обзор, не параллельный трекер.

## Пока не известно

Имя и специализация психолога, аудитория, образование и опыт, список услуг и цены, фото и юридические реквизиты, канал записи, домен и стек. Всё это уточним на брифе и не будем додумывать.

**Важно:** публичный репозиторий не предназначен для личной переписки, договоров, персональных данных, полной версии брифа или историй клиентов.
