# Безопасность и публичность

**Публичный GitHub — не хранилище всех клиентских материалов.**

## Что можно публиковать

- Структуру и обезличенную документацию проекта, задачи, выводы об открытых референсах.
- Подтверждённые и согласованные для публикации тексты и фотографии с соответствующими правами.
- Исходный код и конфигурацию без секретов.

## Что не размещать без отдельного разрешения

- Полные ответы брифа и непубличную информацию заказчицы.
- Частную переписку, договоры, счета, персональные контакты, реквизиты.
- Истории конкретных клиентов, информацию о здоровье и чувствительные данные.
- Неутверждённые портреты и скриншоты личных кабинетов.
- Перепечатанные отзывы/материалы без подтверждённых прав.
- Пароли, токены, ключи API, доступы к сервисам и хостингу.

## Правила

- Секреты — в `.env` или менеджере секретов (не коммитить). В репозитории может быть только `.env.example` без реальных значений.
- Файлы в `private/` и `client-private/` игнорируются Git.
- Удаление коммита **не гарантирует** удаление опубликованных данных из историй и чужих копий.
- Публичный репозиторий можно перевести в приватный, но прежние публичные форки/копии могут сохраниться.
- Окончательные юридические требования к сайту и формам уточняются до публикации.
