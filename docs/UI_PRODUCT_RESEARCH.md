# Продуктовые UX/UI-референсы для сайта психолога — исследование №3

**Дата:** 30 октября 2026.  
**Статус:** ПОИСК / НЕ УТВЕРЖДЕНО. Новые примеры — только для обсуждения, не добавлять к утверждённым визуальным референсам без одобрения исполнителя.

## Обратная связь исполнителя — что реально важно

- Из реальных сайтов психологов **продолжают нравиться только Анастасия Колоскова и Артём Праведный**.
- Подборка из второго исследования (Мария Кочеткова, Алиса Серик, Анастасия Яворовская и др.) **не подошла**: слишком много текста, мало воздуха, устаревающая эстетика, повторяющиеся асимметричные секции, крупные шрифты с засечками.
- Искать вдохновение в **современных мобильных приложениях и digital-продуктах**, где много воздуха, округлые карточки и кнопки, ясная иерархия, мягкая визуальная система, аккуратная типографика **sans-serif**, ощущение доверия, элегантности и человечности.
- **Не делаем сайт похожим на dashboard** и не копируем приложение буквально: остаётся персональный одностраничный сайт с реальным психологом, услугами, образованием и записью.
- Цветовая палитра **только от заказчицы (пять Dulux-кодов)**, чужие бренд-цвета не переносим.
- Дизайн и прототип делает Open Design; здесь фиксируем исследование и принципы, ничего не генерируем без запроса.

## Кандидаты на продуктовые UX/UI-референсы (НЕ утверждены)

### 1. Stoic — https://www.getstoic.com/

**Взять:** редактуру информации до минимума, ясный sans-serif, крупные короткие заголовки, минималистичные округлые CTA, визуальное разделение одного шага от следующего. Варианты экрана без перегруза: https://www.apple.com/ke/newsroom/2025/09/apples-foundation-models-framework-unlocks-new-intelligent-app-experiences/

**Не брать:** stark чёрно-белую палитру буквально; эмоциональный трекинг, вопросы о настроении и привычки не нужны на визитке психолога.

### 2. Gentler Streak — https://gentlerstories.com/gentlerstreak

**Взять:** мягкая карточная система, уважительные состояния UI, маленькое количество информации на карточке, просторные поля, круглые акценты, очень ясные microcopy, приятные лёгкие формы.

**Не брать:** игровые иллюстрации, спорт-метрики, цветные градиенты, блеск Liquid Glass как самоцель.

Подтверждение более мягкой ревизии UI: https://gentlerstories.com/newsroom/20250911gentlerstreakios26 ; https://gentlerstories.com/newsroom/20260914ios27

### 3. Linear (UI-дисциплина, не отраслевой визуальный референс) — https://linear.app/now/behind-the-latest-design-refresh

**Взять:** интеллектуальную визуальную иерархию, мягкие разделители, сдержанную навигацию, отступы между элементами, отсутствие равнозначно кричащих элементов интерфейса. 2026 refresh принцип «structure should be felt not seen».

**Не брать:** SaaS-дашборд, тёмные product-панели, статусные бейджи повсюду, огромное количество интерактивных контролов.

### 4. How We Feel — https://howwefeel.org/

**Взять:** лаконичные названия тематических карточек, язык без сложного жаргона, очень простое визуальное различение вариантов, дружелюбие без заумности. Дизайнерский разбор: https://www.bpowell.co/design/how-we-feel

**Не брать:** радугу эмоций и игровой тёмный интерфейс, они противоречат сдержанности Dulux и зрелому позиционированию.

### 5. Apple Health / State of Mind — https://www.apple.com/health/

**Взять:** однозначную навигацию, ценность одного понятного шага, чёткий контраст, поддержку доверия спокойной структурой, принцип «сначала главное, подробности по запросу». Официальная документация: https://support.apple.com/guide/iphone/log-your-state-of-mind-iph6a6decb13/27/ios/27

**Не брать:** системные элементы iOS буквально, медицинскую символику, сложные интерфейсы для отслеживания эмоций.

### 6. Balance (дополнительный, не основной) — https://support.balanceapp.com/hc/en-us/articles/4407700854171-What-is-Balance

**Взять:** светлую композицию карточек категорий и дружелюбные текстовые названия.

**Не брать:** старые промо-скриншоты как доказательство современности дизайна; стиль иллюстраций может старить сайт. Только UX-принцип.

## Как переносить UX/UI-принципы в лендинг

| Элемент сайта психолога | Адаптация из продуктового UX |
|---|---|
| Первый экран | Короткий ясный заголовок на современном гротеске, 1 основное действие, фото реального специалиста, большое свободное поле |
| «С чем помогаю» | 4–6 округлых карточек с одной короткой мыслью и 1 строкой контекста; без абзацев по 100–150 слов |
| Обо мне | Фотография + 2–4 сжатых смысловых тезиса; подробности раскрыть локально, без гигантской простыни |
| Квалификация | Компактные группы или таймлайн 3–5 пунктов, не выкладывать длинную биографию во весь экран |
| Услуги | 1–3 ясные карточки формата, длительности, цены и способа записи |
| FAQ | 5–7 коротких вопросов в аккуратном аккордеоне |
| Отзывы | Один спокойный виджет или ссылка на официальный профиль при разрешённой интеграции |
| Финальный CTA | Один простой путь записи, понятная подпись о следующем шаге |

## Визуальные правила для следующей концепции

- Sans-serif-first (например, современный нейтральный гротеск). Засечки не обязательны и, судя по отзывам, скорее **нежелательны**.
- Более симметричная или упорядоченная сетка; асимметрия только ради смысла.
- 16–24px радиусы для крупных карточек как рабочая гипотеза, а не жёсткое правило.
- Использовать фоновые поверхности из Dulux, не вводить произвольную кремовую палитру.
- Прозрачная типографическая иерархия, короткие абзацы, нормальные размеры на mobile.
- Фото психолога и подтверждённые профессиональные данные — главный источник доверия, не графическая декоративность.
- Удерживать художественный минимализм без превращения одностраничника в интерфейс мобильного приложения.
- **Не рисовать прототип до выбора приемлемого направления.**
