# Контекст проекта

**Обновлено:** 2026-10-29  
**Этап:** исследование и подготовка к будущему брифу.

## Подтверждённые вводные

- Заказчица — психолог. Готовой концепции и референсов сайта пока нет.
- Предоставлено изображение с пятью образцами Dulux — визуальный ориентир по цветам.
- Исследование, дизайн и разработка сайта — задача исполнителя.
- MVP — небольшой персональный **одностраничник**.
- Цель: показать специалиста, его деятельность, опыт, услуги и дать возможность записаться.
- Возможны материалы/статьи и кейсы, но их необходимость и допустимость нужно уточнить.
- Отзывы со страницы «ПроДокторов» желательно использовать, но способ интеграции не подтверждён.
- Бриф проведём позже: требования к услугам, специализации и содержанию сейчас неизвестны.
- Задачи ведём в GitHub Issues без GitHub Projects. Репозиторий публичный.

## Рабочие гипотезы

- Сценарий посетителя: понять, подходит ли специалист → убедиться в компетентности → изучить условия → записаться.
- Подход к оформлению: современный, спокойный, тёплый, минималистичный.
- Подача без громких обещаний результатов и псевдотерапевтических образов.
- Визуальные решения и окончательную структуру согласуем после изучения референсов и брифа.
- CMS и отдельные статьи добавляем только если они реально нужны.

## Неизвестно до брифа

Специализация, аудитория, имя/публичные контакты, методы и подтверждённый опыт, услуги/цены, фото, город/онлайн, способ записи, право на публикацию материалов, домен, стек.
